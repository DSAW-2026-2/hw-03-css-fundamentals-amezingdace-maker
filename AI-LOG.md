# AI Log — HW03

## Secciones generadas con apoyo de IA

Se utilizó IA como apoyo para desarrollar y revisar diferentes partes de `styles.css`.

La IA ayudó principalmente con:

- El uso de CSS Grid para las tarjetas de películas y del equipo.
- El uso de Flexbox para el header y los formularios.
- La organización del diseño responsive mediante media queries.
- La revisión del box model usando `margin`, `padding` y `border`.

## Modificaciones realizadas

Después de revisar el CSS generado, se ajustaron colores, espacios, tamaños de fuente y la distribución de algunos elementos para adaptarlos al diseño de CineHub.

También se revisó el comportamiento responsive para que las tarjetas y la navegación se adapten correctamente a diferentes tamaños de pantalla.

## Parte más difícil de entender

Lo más difícil de entender fue decidir cuándo utilizar Grid y cuándo utilizar Flexbox.

La IA explicó que Grid es más apropiado cuando se necesita controlar filas y columnas al mismo tiempo, mientras que Flexbox funciona mejor para organizar elementos principalmente en una sola dirección.

Por eso se utilizó Grid para las tarjetas y Flexbox para el header y los formularios.
